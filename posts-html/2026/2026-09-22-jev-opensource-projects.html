使用 Jev 最火的开源项目盘点

Jev 是 TypeSafe AI 于 2026 年 9 月 15 日开放早期访问的首个 System One（系统一）模型——不生成文本，只返回带校准概率的结构化判断。本报告盘点其发布一周内 GitHub 上最火的相关开源项目，全部数据经 GitHub API 实时核实。

数据快照：2026-09-22（GitHub API 实时核实） 收录项目：20 个 License：绝大多数 MIT 头部项目 Star：17.5k+

背景：Jev 是什么，为什么一周长出整个生态

Jev 的定位是「代码拥有工作流，模型只负责判断」：开发者提供 state（上下文）和一组明确的问题与候选项，Jev 在约 70–500ms 内返回类型化答案与校准概率，输出免费、不可自由发挥文本。这种「决策原语」形态催生了一批把 Jev 当作决策层嵌入 Agent 循环的开源项目。

三种判断原语
Choice 从固定选项中选一 · Noul 返回某事件成立的概率 · Score 在有序刻度上定位程度，可跨条目比较用于排序。
关键数字
$0.042 / 百万输入 token，输出免费；最多 255 个选项；官方基准约 68% 准确率（四工作流），校准是卖点但不等于单次正确。
模型本体闭源
Jev 无权重、不可自托管，仅通过 console.typesafe.ai 或 Vercel AI Gateway 访问。GitHub 上不存在「Jev 模型仓库」，开源的是使用与复现它的项目。
读前须知：生态内所有项目都诞生于 2026-09-15 发布后的一周内，尚未经过生产环境长期验证；Star 数衡量关注度而非质量。Vercel 称 Jev 是 AI Gateway 历史上采用最快的模型，数字仍在快速变动。

分类详表：四大生态位

Jev 生态项目呈现清晰的四种形态：① 把 Jev 作为决策层的 Agent 应用；② 围绕 Jev 的开发与效率工具；③ 模式 / 提示词 / 起步代码的资源清单；④ 不依赖官方 API 的开源复现与兼容实现。

① Agent 应用 —— Jev 作为循环中的决策层

browser-use/jev-ultrafast ★ 17,563

Fastest and cheapest web agent · browser-use 官方出品，被视为 Jev in-the-loop 的参考实现。

生态观察与风险提示

4 类
形态收敛很快
发布仅一周，项目已收敛为四个生态位：决策层 Agent、效率工具、资源清单、开源复现。值得读的项目都把 Jev 当作更大循环中的决策层，而非独立产品。
MIT
许可证高度统一
核实过的项目中绝大多数采用 MIT（个别 Apache-2.0），少数未标注许可证的仓库（minecraft-agent、SemIf 之外的清单类）引用代码前需先确认授权。
复现≠复刻
开源复现只复刻了接口
SemIf、LocalJev、openjev 系列复现了「多选项出概率」的接口形态，但没有复现 RLCD 校准训练与并行采样器——Jev 概率可信的核心部分不在开源世界里。
1 周
全部未经生产验证
除 hippo-memory 外，所有项目都创建于发布后数日内，尚无生产部署存活记录；jev-trader 更处于高风险的交易领域。接入任何项目前先读代码、跑 dry-run。
