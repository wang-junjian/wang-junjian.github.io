00

概览：一句话与三大件

Qwen3-ASR 是阿里千问于 2026 年 1 月开源的语音识别模型家族，包含 Qwen3-ASR-1.7B、Qwen3-ASR-0.6B 两个识别模型，以及一个专门预测时间戳的 Qwen3-ForcedAligner-0.6B。

它采用经典的编码器—解码器结构，但解码器直接复用 Qwen3 文本大模型，因此天然继承了语言知识与多语言能力。整个系统由三大件串联：

01 / ENCODE

AuT 音频编码器

把波形压缩成 12.5Hz 的声学 token，并用动态窗口的 Transformer 编码成语义表示。

02 / PROJECT

Projector 投影层

一个线性层，把声学表示对齐到 LLM 的词嵌入空间——翻译成语言模型看得懂的语言。

03 / DECODE

Qwen3 LLM 解码器

1.7B 或 0.6B 的文本大模型，带 Q/K Norm 与 MRoPE，自回归地吐出文字 token。

04 / ALIGN

ForcedAligner（旁路）

独立的非自回归模型，并行吐出所有词的起止时间戳，与识别主模型解耦。

核心洞察流式与离线不是两个模型，而是同一套权重通过调节注意力窗口大小切换的两种工作模式。这是整个设计里最关键、也最省成本的一点。
01

整体架构：数据如何流过系统

从 16kHz 的 WAV 波形到最终文字，数据依次经过三个串联组件。每一步都在"降维"：把高冗余的音频信号，逐级压缩成信息密度更高、语言模型可处理的表示。

02

声音如何变成 token

这是 AuT（Audio Transformer）编码器内部发生的事，也是它区别于传统 ASR 的关键。音频并不是一次性整段喂进去的，而是被切块、压缩后再编码。

  1. 提取 Mel 频谱16kHz 波形经 STFT（窗长 25ms、步长 10ms）转成 128 维 Fbank / Mel 特征，帧率 100Hz，即每 10 毫秒一帧。
  2. 分块卷积，8 倍下采样Mel 不是整段处理，而是切成 100 帧一块，每块独立做 3 层 Conv2D。每 100 帧压缩为 13 个 token，帧率从 100Hz 降到 12.5Hz——1 秒声音只剩约 12 个 token。
  3. 带窗口的 Transformer 编码下采样后的 token 序列进入 Transformer。注意力被限制在动态窗口内（训练时 1–8 秒，推理时固定 8 秒约 104 个 token），窗口之间互不attend。
  4. 分块位置编码正弦位置编码按块施加（每块从位置 0 重新计数），而非全局连续——这是支持任意长度流式输入的一个工程细节。

降维的收益很直接：序列缩短 8 倍后，注意力计算量大幅下降，模型才能做到高吞吐。下面是两个识别模型的关键参数对比（来自社区对权重结构的逆向整理）：

03

流式与离线的统一：动态注意力窗口

传统方案里，流式识别（低延迟）和离线识别（高精度）通常是两个独立训练的模型。Qwen3-ASR 用同一个模型、同一个权重覆盖两者，靠的就是 AuT 中 1–8 秒可调的动态注意力窗口。

这一设计让模型在部署时更灵活：实时字幕用小窗口保证首字快速吐出，录音转写用大窗口追求准确率，而后端只需维护一套权重。

04

四阶段训练：从听懂声音到写好文字

能力是逐级"喂"出来的——先学会通用的声学表示，再吸收多模态知识，然后专项攻克 ASR 任务格式，最后用强化学习打磨输出。

05

词级时间戳：ForcedAligner

转写文本由主链路生成，但"每个词在音频里的起止时间"并不是主模型逐步吐出的，而是交给一个独立的 Qwen3-ForcedAligner-0.6B。它把强制对齐任务改造成非自回归（NAR）时间戳预测：不再逐 token 串行生成，而是一次性并行输出所有词的时间点。

为什么重要

快，且可扩展语言

并行预测把对齐从"逐词等待"变成"一次算完"，单并发推理效率极高；支持 11 种主流语言、5 分钟以内音频的任意位置时间戳，精度据报告超越 WhisperX 等级联方案。

怎么用

与主模型组合

识别模型出文字、ForcedAligner 出时间轴，两者组合即可得到带词级时间戳的转写稿——这是字幕生成、语音标注、音视片段分析的基础能力。

歌唱识别、噪声/远场鲁棒性、方言混读等复杂场景，也是这套架构在训练阶段专项增强后的产物，并非仅靠主模型结构。

07

小结：三个值得记住的点

  1. 一条流水线声音 → Mel 频谱 → 8× 下采样的 12.5Hz 声学 token → Projector 对齐 → Qwen3 解码器自回归出文字。本质是让文本大模型"读懂"声音。
  2. 一套权重两种模式1–8 秒动态注意力窗口让流式与离线共用同一模型，而不是分别训练两个——部署成本和运维复杂度都大幅降低。
  3. 时间戳独立旁路ForcedAligner 用非自回归方式并行吐出词级时间戳，与主识别链路解耦，兼顾速度与精度。

如果继续深入，值得关注的三个具体问题：分块卷积为何能天然支持流式输入、MRoPE 在音频 token 上如何作用、以及 ForcedAligner 的非自回归对齐损失函数如何构造。
