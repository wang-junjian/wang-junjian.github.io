一句话判定

中国引领的是「全球开放权重的供给与开发者默认基座」，不是「全球 AI 的前沿能力、价值捕获与治理标准」。把这两件事合成一句「引领全球」，会在采购、投资和立项决策上产生系统性误导。前者的证据是多条独立口径一致指向的高置信事实；后者的证据同样明确，且方向相反。

  1. 「引领」必须分维度判定，不能当布尔值。拆成供给规模、默认基座、前沿能力、企业价值捕获、治理与标准、商业可持续性六项后，中国在前两项明确领先、第三项快速追赶、后三项落后或未定。大样本观察 · 多源
  2. 供给与生态领先是硬事实，且可复跑。Hugging Face 春季报告：过去一年中国模型占 Hub 下载 41%；ATOM Report：截至 2026-03 中国主线开放语言模型累计下载 11.5 亿次 vs 美国 7.23 亿次；2026-02 中国架构占新衍生模型 70%。三个不同口径方向一致。一手平台数据 + 学术论文
  3. 真正值钱的不是下载量，是「默认基座」的锁定效应。Qwen 在 Hub 有 151,448 个衍生模型（Meta 总量的 2.6 倍、Llama 仓库的 4.7 倍），日均新增 180–210 个；2026 年 1–8 月 Qwen 下载约 20.45 亿次，是只发前沿大模型的 Moonshot（3700 万）的约 55 倍。全尺寸谱系比参数天花板更能转化为采用。一手平台数据
  4. 驱动力是经济位势，不是路线信仰。178 个中国 >20B 参数发布中 59% 用 Apache 2.0、22% 用 MIT；美国同尺寸仅 29% 是宽松许可、41% 自定义条款、30% 未声明。既然收益不在许可费，就必然迁移到 API、云、芯片与私有化部署；后发者用开放换生态位是理性选择。一手平台数据
  5. 技术贡献是真实的效率创新，且带约束倒逼的痕迹。MoE 把激活率压到约 3%–4%（Kimi K3：2.8T 总参、每 token 激活 16/896 专家）；混合注意力收敛到 3:1 便宜层与精确层交替；DeepSeek-V4 在 1M 上下文下只需 V3.2 的 27% 单 token FLOPs 与 10% KV cache。厂商技术报告 · 待第三方复现
  6. 「开放权重」不等于「开源」，而且透明度在倒退。按 OSI 的 OSAID 1.0，旗舰模型没有一家交齐数据信息、训练代码、参数三要素；训练数据披露按下载加权从 2022 年 79.3% 降到 2025 年 39.8%；Foundation Model Transparency Index 均分 58→40，DeepSeek / Meta / Alibaba 平均仅 30。学术论文 + 指数报告
  7. 前沿能力与企业预算仍在美国闭源体系。Artificial Analysis Index v5（2026-10-27，60% 私有测试集）把开放与闭源差距从 3 分拉到 12 分；已发布权重的最高分 32，落后榜首 26 分；Epoch ECI 口径下开放模型滞后约 4 个月；Menlo 报告里前沿模型支出份额 35%→63%，三家美国实验室拿走 69% 部署支出。一手评测 + 一手调查
  8. 采用量在涨，价值捕获没有同步。美国企业开源模型 token 份额 11%→19%，支出份额却 6%→4%，均价一年降 3.3 倍到 $0.13/百万 token。中国模型拿下开源支出的 89%，但开源只占全部模型支出的 4%——赢了赛道，也把这条赛道的价格压了下去。一手调查 + 建模估算
  9. 最缺的不是模型，是治理层与反馈闭环。15 万个衍生模型每天都在免费标注基座缺陷，但海外衍生的评测结果、失败案例、领域数据没有结构化回流通道，也缺少类似 Linux 基金会的中立模型治理组织。下一轮胜负手在这里，不在再刷一次参数上限。行业观点 · 可证伪

01范式判定：什么才算「引领」

先把命题变成可证伪的判别式，再谈数据。否则「下载量第一」和「技术第一」会被轮流拿来支撑同一个结论。

1.1 六个判别问题

「引领全球」在日常语境里至少混了六种不同主张。把它们拆开，每一问都能找到对应的一手指标，也都能被某个数字推翻：

Q1 谁在供给？

开放权重发布数量、参数上限、下载份额。对应 Hugging Face 春/夏报告与 ATOM 累计下载。这是「供给引领」。

Q2 谁被当作底座？

衍生模型数、微调基线占比、量化与工具链覆盖、默认模板。这是「生态引领」，比 Q1 更能预测下一轮。

Q3 谁在最难的任务上更强？

私有留出集上的智能指数、能力滞后月数、智能体与科研任务通过率。这是「能力引领」。

Q4 谁拿到钱？

企业模型支出份额、部署预算、每完成任务成本与毛利。这是「价值引领」。

Q5 谁定规则？

许可证范式、评测方法、透明度指数、中立治理组织、标准互认。这是「治理引领」。

Q6 谁能长期做下去？

迭代节奏、维护 SLA、变现路径、算力与人才供给、反馈回流通道。这是「可持续引领」。

判别式：只有当 Q1–Q6 中至少四项同时领先、且 Q3/Q4 不显著落后时，「引领全球」才是稳健表述。按 2026-11 的证据，满足的是 Q1、Q2；Q3 有进步但落后；Q4、Q5、Q6 落后或未验证。因此命题不成立为全称判断，成立为限定判断。

02理论根基：为什么必须是这个形状

本章不复述新闻，而是给出四条能推出具体工程动作的机理。好理论的标准是：读完知道下一步该改什么。

2.1 后发者的生态位交换：开放是经济选择，不是路线信仰

北京智源研究院副院长叶启威给了一个很干净的判据：开源与闭源之争「与其说是技术路线之争，不如说是经济选择」——开源是客户优先，先帮下游找到落地路线；闭源更关注模型本身的成长；更底层的原因是跟跑者需要靠开源占据生态位 [S18]。

这个机理可以推出一组可被证伪的预测，而 2026 年的数据恰好逐条对上：

2.2 网络效应与六周窗口：衍生模型是资产，下载量只是流水

一个团队在 Qwen 上做了一次微调，下一版项目大概率还在 Qwen 家族里选——工具链、量化版本、教程、踩坑记录、团队肌肉记忆全都是转换成本。于是每一次衍生都在降低下一次采用的门槛，形成正反馈。Hugging Face 的报告把这条反馈的另一面也量出来了：开放模型的参与度几乎在发布后立即见顶，平均参与时长约 6 周；DeepSeek 靠 V3→R1→V3.2 的连续发布维持竞争力，停滞的组织会迅速把份额让给高频更新者或领域微调者 [S1]。

这解释了一个反直觉的现象：旗舰模型拿到「点赞」，老的小模型拿到「下载」。夏季报告取 2026 年下载 top 25 与点赞 top 25，只有一个仓库同时出现在两张榜；all-MiniLM-L6-v2 七个月被拉取 15.5 亿次，却只有 5156 个赞；2026 年发布的模型没有一个进入下载 top 25，13/25 是 2022 年的老模型 [S2]。点赞衡量「这个发布重要」，下载衡量「它已经被焊进某条定时跑的流水线」。

可执行的推导：监控体系里把「关注」和「依赖」分成两条曲线；把版本节奏写进对外 SLA，而不是等竞品发布再响应；用衍生模型数、稳定下载、企业工作流嵌入做健康度指标，不要用点赞或发版日峰值。

2.3 约束倒逼效率：让单位智能更便宜，而不是让算力更多

当训练与推理的算力供给受限时，优化目标被迫从「总能力」转向「单位成本的能力」。这在工程上等价于排队论里那句常被误用的建议：应该让验证更便宜，而不是让评审更慢——压低每个 token 的计算与显存开销，比延长推理链或堆更多卡更能扩大可服务规模。2026 年中国模型呈现的技术收敛正是这条约束的影子（详见 05 章）：

  • MoE 极致稀疏：总参数决定知识容量（主要吃存储），激活参数决定每 token FLOPs。Kimi K3 2.8T 总参、每 token 只激活 16/896 个专家，激活率约 3%–4%。
  • 混合注意力 3:1：三家实验室独立收敛到「3 层便宜的线性/压缩注意力 + 1 层精确全局注意力」的块结构，把 KV cache 从随长度线性增长压成受控状态。
  • 低精度与分发层：FP4/FP8 混合、MXFP4 权重、社区量化（GGUF）让万亿参数模型在消费级硬件上可跑；Qwen 的 GGUF 月下载 3960 万，约为 Llama 的 5 倍 [S2]。
  • 可核验的效率数字：DeepSeek-V4-Pro 在 1M token 上下文下只需 V3.2 的 27% 单 token FLOPs 与 10% KV cache [S15]。

证据强度说明：架构参数与效率比来自厂商技术报告与模型卡（[S15] 及同类），属「自报 + 可复现配置」，尚未见大规模独立第三方复现；3:1 收敛的跨厂商归纳来自技术评论，属单一来源归纳，本报告标为中等强度。

可执行的推导：选型时把 FLOPs/任务、KV cache/上下文长度、每完成任务成本 列为一级指标；「参数量」只当存储与部署门槛看，不当能力代理。一个需要更长推理、更多重试的便宜模型，可能比一次通过的前沿模型更贵 [S6][S24]。

2.4 Goodhart 定律与评测污染：公开榜单是会被优化掉的

当静态评测变成优化目标，它就不再是好指标。2026-10-27 Artificial Analysis 把 Intelligence Index 升到 v5，60% 权重改由私有测试集或留出答案构成（新增 FrontierCode 2.0、Terminal-Bench-Science，升级 HLE-Diamond 等）。结果不是某一家的排名变化，而是开放与闭源的整体差距从 3 分扩大到 12 分：v4 时代看起来接近追平的开放权重模型，在更难被记忆的任务上露出了真实距离 [S6]。

这不是「作弊」的指控。训练语料吸收了互联网上公开的题目与解法，风格模仿与窄域优化会在公开榜单上产生系统性高估；v5 的设计正是对这一机制的工程回应。代价同样真实：私有测试集无法被外部检查错误、歧义或捷径，于是「更可信的分数」与「更不可复核的分数」同时出现。

这条理论推出的是最实用的一条纪律

任何团队都应自建 30–50 条来自真实业务、有已知正确答案的留出样例，每次换模型、换版本、换 Prompt 都跑一遍；公开榜单只用于缩小候选集，绝不用于验收。同时记录每完成任务成本而非每百万 token 单价 [S6][S20]。

2.5 权力扩散之后是再集中：别把「去中心化」写进结论

MIT 与 Hugging Face 联合的《Economies of Open Intelligence》用 851,000 个模型、200+ 属性、22 亿次下载、2020-06 至 2025-08 的完整周度日志，测出的是一次双向运动：Google / Meta / OpenAI 等美国大厂的主导性显著下降，独立或无隶属开发者的下载占比从 17% 升到 39%，产业在开发中的份额从约 70% 降到 37%；但作者同时警告，DeepSeek 与 Qwen 的崛起「可能预示着市场力量的新一轮整合」[S4][S1]。

集中度数据支持这个警告：Hugging Face 上约 85.6% 的模型终身下载不足 200 次，1.5% 的仓库占 99.2% 的下载；春季报告里 top 200 模型（0.01%）占 49.6% 下载 [S2][S1]。开放降低了进入门槛，却没有自动带来均匀的分布。

可执行的推导：采用开放权重的理由若是「避免锁定」，就必须同时建设可替换性——OpenAI 兼容接口、可迁移的评测集、至少两家备选后端、权重与配置自留档。只换供应商、不换治理方式，等于把锁定从合同搬到事实标准里。

3.2 反证据：下载量是最容易被高估的指标

承认领先，同时必须承认这个指标的天花板。以下五条是同一批一手报告里给出的自我修正：

  1. 下载 ≠ 部署。ATOM 作者明确写道「downloads measure interest, not production use」，并用 2.5×IQR 过滤 CI/CD 管道与机器人造成的日下载尖峰 [S3]。
  2. 下载 ≠ 关注度。夏季报告 top 25 双榜只有 1 个重合；2026 年发布无一进入下载 top 25 [S2]。
  3. 结构极度偏斜。85.6% 的模型终身下载 <200 次，1.5% 仓库占 99.2% 下载；<1B 小模型占全时下载 83%，>100B 只占 1% [S2]。
  4. 企业侧另有分母。Menlo 对近 400 位美国企业决策者的调查显示，开源模型占生产 token 19%、占模型支出 4%；Linux Foundation 的 63%「使用开放模型」与 Menlo 的 11%「企业 API 份额」并不矛盾——一个是「栈里有没有」，一个是「钱花在哪」[S5][S13]。
  5. 归国规则会失真。Epoch 的 964 个开放权重语言模型里，美国 461 条、中国 333 条、法国 70 条、145 条跨国多标签；一个模型常同时记多个国家，总部字段不等于贡献者网络 [S14]。

结论的收敛

04默认基座之争：Qwen 为什么比参数天花板重要

本章回答 Q2。生态领先不是靠一次最强发布，而是靠「让别人的下一个项目仍然从你开始」。

4.1 两种产品策略，差 55 倍

Hugging Face 夏季报告把中国实验室分成两派：Moonshot、MiniMax、小米、Z.ai 几乎不发 70B 以下的模型，开发者的第一次接触就是一个自己跑不动的巨物；腾讯与阿里 Qwen 则覆盖从 <1B 到万亿的全尺寸。报告用同一年度的下载量给出了结果：Moonshot 的前沿-only 组合约 3700 万次下载，Qwen 的全谱系组合约 20.45 亿次，相差约 55 倍（含全部仓库为 20.61 亿）[S2]。

这不是能力差距，是可触达面积的差距。一个 0.6B 模型会进入手机、边缘设备、CI 流水线和教学代码；一个 27B 模型刚好落在单张消费卡上；一个 2.4T 旗舰主要靠托管 API 被使用。三者共享同一套 tokenizer、模板、工具链与文档，让开发者在算力变化时不必更换家族。

4.2 飞轮的四个齿轮

① 谱系覆盖给出入口

从 0.6B 到 2.4T 的尺寸族，覆盖边缘、单卡、数据中心与托管 API；低门槛版本是开发者第一次接触的地方 [S3][S2]。

② 量化社区做免费分发层

Unsloth 等社区账号把大模型压成可跑的格式，是 Hub 第三大衍生来源；GGUF 月下载 Qwen 3960 万、Gemma 2080 万、Llama 750 万 [S2]。

③ 宽松许可消除法律摩擦

能商用、能改名、能再分发，企业法务不必逐版本谈判；这是衍生模型得以日均新增 180–210 个的前提 [S2]。

④ 稳定节奏形成预期

ATOM 把 Qwen 的成功归因于「广谱发布策略」与发布一致性；2026-02 Hub 上 69% 的新微调模型基于 Qwen [S3]。

四个齿轮合起来的结果是一个自增强回路：尺寸越全 → 愿意微调的人越多 → 衍生、工具、教程、量化版本越多 → 下一批人再选底座时还是它。ATOM 报告据此提出相对采用指标 RAM（把模型下载量按同尺寸类别前 10 名基准归一化），并给出对生态深度最直接的结论：长期采用由「家族深度」驱动，而非某一次顶尖发布 [S3]。

4.3 许可证是分发策略，不是法律细节

反常识的推论：「开放」在 2026 年已经是一种定价策略。权重免费送出，收益必须来自别处：API 调用、云与算力、芯片适配、私有化交付与生态位本身。中国厂商在协议宽松度上的领先，成本几乎为零，却是海外开发者默认选择权的关键来源 [S2][S21]。

4.4 但宽松不是永久承诺：收入门槛正在回来

夏季报告在结论里留下了一个转折：「最近几周，我们看到这一趋势在真正的大模型上开始改变」——Kimi K3 与 Qwen3.8 2.4T 开始加入非商业限制与收入分成要求；与此同时 DeepSeek 与 Z.ai 仍以纯 MIT 发布 700B–1.65T 模型 [S2]。行业访谈给出的条款细节包括月活、月收入标注义务与 MaaS 转售阈值等「成功惩罚条款」：早期无感，恰在业务跑通那一刻触发 [S21]（二手访谈，选型时须逐版本核对 LICENSE 原文）。

这构成一条明确的风险线：按今天的业务规模评估许可合规成本，会系统性低估三年后的成本。许可证必须按「目标规模」而不是「当前规模」审。

4.5 反证据：谱系策略的代价与锁定风险

  • 维护成本被隐藏。470+ 款模型意味着 470+ 套文档、评测、安全补丁与废弃策略；Hugging Face 测得平均参与时长约 6 周，停止更新的组织会迅速失份额 [S1][S18]。
  • 版本碎片化。衍生模型多不等于质量高；RedMonk 对约 290 万个 Hub 模型的扫描发现近 70% 根本没有许可证标签，标签只是筛查信号、不是法律清理结论 [S14]。
  • 采用者承担升级跑步机。「免费权重不是免费系统」：GPU、运维、每次升级的重新评测、何时迁移的决策全由使用方承担；为独立性而采用开放权重却永不升级，结果比被供应商锁定更糟 [S20][S23]。
  • 事实标准也是锁定。当 69% 的新微调基于同一家族，tokenizer、模板与工具链的迁移成本就成了新的护城河。这与 2.5 节的「再集中」警告是同一件事 [S3][S4]。

05技术解剖：效率创新是真的，边界也是真的

本章回答「凭什么」。四层技术收敛共同压低单位智能成本，但它们擅长的是成本与吞吐，不是开放式科研推理。

5.1 四层技术栈

第一层 · 稀疏 MoE

总参数决定知识容量（主要吃存储），激活参数决定每 token 计算。Kimi K3：2.8T 总参、约 104B 激活、896 个专家每 token 激活 16 个；DeepSeek-V4-Pro：1.6T / 49B 激活；Qwen3.8-Max：2.4T / 95B。激活率普遍落在 3%–4% 区间 [S15][S24]。

第二层 · 混合注意力

拒绝每层都做精确 softmax 注意力，改为「3 层便宜算子 + 1 层精确全局层」交替。Kimi K3 用 KDA:MLA＝69:24，Qwen3.8 用 Gated DeltaNet 与门控注意力 69:23，GLM-5.3-Flash 线性注意力与稀疏注意力 34:11；DeepSeek-V4 用 CSA + HCA 两种压缩注意力 [S15][S24]。

第三层 · 长上下文与低精度

1M token 上下文成为 2026 年旗舰标配；FP4/FP8 混合、MXFP4 权重、INT4 量化把部署门槛压到可管理范围。可核验的效率比：V4-Pro 在 1M 上下文下只需 V3.2 的 27% 单 token FLOPs 与 10% KV cache [S15]。

第四层 · 硬件与分发适配

中国开放模型发布时明确适配国产芯片，阿里投资推理导向芯片架构；美国侧 AMD 与 NVIDIA 反而成为发布新开放模型最多的两家（各 200+ 仓库），用免费模型证明硬件能跑。开源模型正在成为卖芯片的方式 [S1][S2][S19]。

证据强度分层：模型卡与技术报告中的参数量、上下文长度、许可证属「可复核配置」；FLOPs / KV cache 比值属「厂商自报，配置可复现但缺独立复测」；跨厂商 3:1 收敛属「技术评论的单一来源归纳」。三类不可混为同等强度。

① 参数大不等于能自托管：Kimi K3 的 INT4 权重约 1390GB，DeepSeek-V4-Pro 检查点约 865GB——绝大多数团队只能通过 API 使用它们，「开放权重」在物理上并不等于「本地可持有」。② 单价低不等于总成本低：更长的推理、更多重试、常驻人工复核会吃掉价差；一次通过的前沿模型有时更便宜 [S6][S24]。③ 便宜不覆盖最难任务：见 06 章，Terminal-Bench-Science 上最佳已发布开放权重仅 13%，而领先闭源 63% [S6]。

5.4 理论回扣：效率创新的能力边界

2.3 节说约束倒逼效率。但效率创新优化的是「给定能力下的成本」，不是「能力上限本身」。AA v5 的科目分布把这个边界画得很清楚：开放权重模型在有明确用户需求、可验证反馈的任务（如终端操作、常规编码）上最接近前沿，在开放式科学推理、多跳深推理上差距最大 [S6][S24]。这提示一个可检验的假设：稀疏化与压缩注意力在「可规格化任务」上几乎无损，在「需要长程探索与自建验证」的任务上仍有结构性代价。目前缺独立复现，本报告把它列为待验证假设而非结论。

支持「尚未引领」的证据

但同一份报告还有三条必须并列的分母：

  • 开源只占全部模型支出 4%；89% × 4% 意味着中国模型在美国企业模型支出里的量级约 3.6%（此为按口径直乘的示意，不是报告给出的数字）。

  • 前沿模型支出份额 35%→63%，Anthropic / OpenAI / Google 三家拿走 69%（1227 亿美元） 的全部部署支出；企业 LLM API 支出里 Anthropic 55%、OpenAI 31%、Google 9%，两家合计 86% [S5]。

「美国企业 89% 的开源模型支出流向中国」是真的；「美国企业 89% 的 AI 预算流向中国」是错的。转述时把「开源模型支出」这个定语丢掉，数字就从一条有力证据变成一条误导。另外原文分项 61+15+11+3＝90，与总计 89 相差 1 个百分点，属四舍五入或分项口径差异，本报告照录不自行修正 [S16][S5]。

7.5 变现路径与可持续性：模型能力不是护城河

开放权重把模型本身变成获客渠道，收入向外迁移到四条路径：托管 API 与推理云、私有化部署与行业交付、云与芯片协同、以及后训练 / 评测 / 工具链服务。行业研究的判断相当一致：单靠模型能力难以维持正毛利，托管 API 定价权被低价供给与云厂商挤压，商业许可在中国开源模型里并非主流收入，私有化部署毛利较好但窗口在收窄 [S19][S24]。Menlo 的数据则从需求侧印证了服务层的机会：后训练采用率从 2025 年 6% 升到 2026 年 10%，而其中 91% 依赖外部伙伴（推理基础设施 50%、专家数据与评测 41%、 specialist 30%，多选）[S5]。

可执行的推导：评估一家开放模型公司，不看 download 与点赞，看四件事——续费率与扩容、单位调用成本与延迟、系统集成与合规能力、长期供应保障。模型能力是入场券，不是持久壁垒；基础设施容量与行业数据闭环才是。这是「商业可持续性」维度判为「未定」的依据。

本章判定

价值捕获层面，中国模型在开放权重这条细分赛道内占据主导（89% 开源支出），但没有改变整体分配格局（开源仅 4% 模型支出，前沿拿走 63%）。更准确的说法是：中国把开放权重做成了全球公共品，同时把它的价格压到了难以靠模型本身赚钱的水平。这是战略成功，也是商业约束。

8.2 为什么开放权重在主权场景里天然占优

Hugging Face 春季报告把机理写得很清楚：开放权重允许政府与公共机构在本国法律框架下用本地数据微调，允许部署在国产硬件上以减少对外国云基础设施的依赖，也让监管审查与公共问责有可检视的对象 [S1]。这与中国 2026 年的政策供给形成呼应：

能力建设

《人工智能合作发展行动计划》提出优质数据供给、智能算力普惠、开源生态共享、规则标准共建等八项行动；面向发展中国家提供五年 5000 个专题研修名额 [S17][S19]。

基础设施

截至 2026-06 国内智能算力规模 2185 EFLOPS、建成 70 余条算力大通道；气象预警方案计划在 30 国落地 [S17][S19]。

多边平台

2026 年乌镇峰会以「开源开放 共建共享」为主题，首个开源主题生态体验馆开馆；世界人工智能合作组织等机制推进知识交流与人才培养 [S17]。

对算力和资本有限、又希望保留本地部署与二次开发能力的机构，开放权重是「能自己持有」的唯一选项。这也是 04 章「宽松许可 + 全尺寸谱系」在国际市场的直接兑现方式。

8.3 三条共同机理，三条边界

机理 · 为什么选它

① 任务不需要前沿智能：摘要、抽取、分类、常规起草、客服占企业工作量大头，付前沿单价是主要浪费。② 数据路径要求：自托管时 Prompt 不出基础设施，这是最强的隐私论证；换成托管 API 同一模型也失去这个好处。③ 可后训练：开放权重给闭源模型基本无法提供的「对模型本身的控制权」，可针对自有任务专精 [S5][S20][S24]。

边界 · 别过度解读

① 多数是单管线、局部工作流，不是整体替换。② 后训练采用率仅 10%，且 91% 依赖外部伙伴，说明能力门槛仍高 [S5]。③ 成本收益里系统重设计的贡献常大于模型替换，把 75 倍全记在模型头上会导致错误的技术决策 [S24]。

给采购方的一句话：采用开放权重的正确理由是「控制」，不是「免费」。控制意味着你同时继承维护、安全补丁、每次升级的重新评测与迁移决策；若组织没有承接这些工作的能力，闭源 API 反而是更便宜的选择 [S20][S23]。

09定义审计：「开源」这个词，两边都没达标

本章回答 Q5。中国引领的是权重分发，不是可复现、可问责的开放。这个区分不是文字游戏，它决定了第三方能不能审计、企业能不能合规、生态能不能回流。

9.1 OSAID 1.0：三要素与尴尬的验证结果

OSI 于 2024-10 发布的 Open Source AI Definition 1.0 要求「修改的首选形式」包含三组要素：数据信息（足够详细，使熟练者能构建实质等价系统）、代码（训练与运行的完整源码）、参数（权重、配置、检查点）。因此一份以 Apache 2.0 / MIT 发布的权重文件是「许可宽松」，但单独并不构成 OSAID 意义上的开源 AI [S10]。

FMTI 的分化尤其值得注意：IBM 拿到 95 分，xAI 与 Midjourney 各 14 分；而三家最有影响力的开放权重开发者 DeepSeek、Meta、Alibaba 平均只有 30 分。「开放权重」并不自动带来「可问责」——这是「权重公开＝透明」这一直觉的直接反证 [S9]。同时 RedMonk 2026-05 扫描约 290 万个 Hub 模型，近 70% 完全没有许可证标签；标签只是筛查信号，不是法律清理结论 [S14]。

一处必须避开的数字陷阱：文献里出现两个 81.4%——一个是 2022 年「开放使用许可占比」，另一个是 2026 年 OpenRouter↔HF join 里「宽松许可桶的下载权重」。二者样本、日期、含义完全不同，只是数字巧合，任何情况下都不能并列引用或用来互证 [S14]。

9.3 许可尽调清单：按三年后的规模审，不按今天审

  • 看协议名，不看「开源」二字。逐版本打开 LICENSE 文件；同一家族不同版本条款可能完全不同。
  • 查商业阈值与「成功惩罚条款」。月活、月收入标注义务、MaaS 转售分成阈值，早期无感、业务跑通时集中触发 [S21]。
  • 查可修改范围与衍生定义。是否限制用输出训练竞品、是否要求保留品牌标注、是否把可接受使用政策传递给下游。
  • 查适用法律与语言版本优先级。双语许可若约定某语种文本优先，争议解决地会改变合规成本 [S22]。
  • 查持续供应。是否有稳定版本维护、废弃策略与安全补丁；Hugging Face 测得平均参与时长约 6 周，停滞即失份额 [S1]。
  • 查上游数据权利。权重许可宽松不等于训练数据、商标、隐私义务已完成清理；OSAID 要求三要素齐备正是为此 [S10][S14]。

[S21][S22] 为行业访谈与评论，属二手观点；条款细节必须以目标版本 LICENSE 原文与法务意见为准，本报告不构成法律意见。

9.4 真正缺的那一层：把 15 万次免费标注收回来

每一次社区微调，都是对基座缺陷的一次免费标注；衍生模型越多，可获得的反馈越丰富。但按行业访谈的判断，当前缺少把海外衍生模型的评测结果、失败案例、领域数据结构化回流到基座训练的机制，也缺少类似 Linux 基金会或 PyTorch 基金会的中立模型开源治理组织。提出的升级方向是把开源从「发布权重」扩展为「权重 + 评测集 + 贡献接收通道」，建立开放中立的治理层 [S21]。

对照来看，规则与元数据基础设施主要由 OSI、Linux Foundation、RedMonk、Stanford CRFM、Epoch AI 等提供；中国侧的优势在供给、场景合作与能力建设（八项行动、普惠算力、多边平台），在中立治理组织、评测方法定义权、机器可读元数据规范上仍是后来者 [S4][S9][S10][S14][S17]。这是六维判定里把「治理与标准」判为落后的核心依据。

9.5 合规与供应链风险：把它当采购变量，不当立场问题

风险项具体表现对采购方的动作
地域化合规差异模型行为受训练时适用的内容与服务规范影响，不同司法辖区对生成内容、数据跨境、行业准入要求不同 [S22]把目标市场的合规要求做成可测样例集，实测拒答率与输出一致性；写进供应商尽调
供应链与政策波动先进芯片出口规则、关税、模型权重访问政策在 2025–2026 年多次调整，影响算力与托管可用性 [S24]保留至少两家可替换后端与权重本地留存；采购合同写明可用性 SLA 与迁移条款
知识产权争议闭源厂商对大规模蒸馏的指控、以及许可兼容性问题，可能传导为下游使用风险 [S14][S22]要求供应商提供训练数据来源说明与赔偿条款；留存模型卡与许可快照

本章判定

「开源」在 2026 年的产业语境里，绝大多数时候是开放权重 + 宽松许可的简称。中国把这一层做到了全球第一，但可复现性、透明度、中立治理与规则定义权仍在别处。把这两层分开，才不会既高估成就、也低估短板。

10.2 反 Goodhart 五原则

  1. 单一指标不当验收标准。公开榜单只用于缩小候选集；任何「差 3 分」或「差 12 分」都是方法相关的测量，不是能力本身 [S6]。
  2. 留出集不公开、不复用、定期轮换。30–50 条来自真实业务、有已知正确答案的样例，是性价比最高的一小时投入 [S20]。
  3. 按「每完成任务成本」核算，不按每 token 单价。v5 里同一批头部模型的每任务成本相差 13 倍以上；便宜模型如果多花三倍推理与重试，可能更贵 [S6]。
  4. 建模值与实测值显式分离。企业份额、市场规模、价格多为自底向上建模估算；平台下载与评测分数是观察值。两者在表格里分列、在结论里不混用 [S5][S14]。
  5. 每个数字带三个标签：年份、分母、证据强度。没有分母的百分比不进结论——这是本报告处理 41% / 89% / 4% / 72.7% 的统一规则。

12.1 三层结论

层内容
事实层截至 2026-11，中国研发的开放权重模型在 Hugging Face 下载份额（41%）、主线累计下载（11.5 亿 vs 7.23 亿）、衍生模型（Qwen 151,448 / 新衍生 70%）、开放模型推理 token（72.7%）与企业开源支出（89%）上均居第一；与此同时，私有留出集评测的能力差距为 12–26 分、能力滞后约 4 个月、开源仅占模型支出 4%、前沿模型拿走 63% 支出、透明度指数 58→40。这些是可以逐条回溯的数字。
判断层
这是观点，不是共识		更准确的表述是：中国引领了全球开放权重的供给与开发者默认基座，但尚未引领前沿能力、价值捕获与治理标准。这不是「半赢」，而是两个不同层面的结果——开放权重被做成了全球公共品，公共品的价格与利润同时被压低；闭源前沿则把最难任务与最多预算留在了自己这边。
行动层对采用方：按六维而非单一指标判断，用私有留出集与每完成任务成本做门禁，把许可证按三年规模审，保留可替换后端。对供给方：把 15 万次社区微调变成可回流的评测与失败案例数据，补上中立治理层与机器可读元数据规范——这比再刷一次参数上限更可能改变下一轮的座次。

12.3 未来 6–12 个月值得盯的三个数

① 能力差距的方向

AA v5 之后的新版本里，「已发布权重最高分」与榜首之差是收窄还是继续扩大。这是「追赶」判断唯一的硬指标。

② 支出与用量的剪刀差

开源 token 份额与支出份额之比（当前 19% : 4% ≈ 4.75）。若比值持续扩大，说明公共品化仍在加速。

③ 回流机制的从无到有

有没有中立的评测集、贡献接收通道、机器可读组件清单。这是「供给领先」能否升级为「治理领先」的先行指标。

最后一句

「中国开源大模型引领全球」作为标题是成立的，作为结论是不完整的。真正值得写进决策文件的，是它后面那句限定：引领的是可被免费下载、自由修改、全球共用的那一层；而决定上限与利润的那一层，竞争才刚进入中段。
