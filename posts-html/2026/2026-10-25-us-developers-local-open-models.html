2先认识几个词

后面反复出现，花一分钟看完这张小词典。

开源权重模型的"大脑文件"可以免费下载到自己机器上跑；不等于训练代码和数据全公开。
量化（Quantization）把模型压缩小、省显存的技术，掉一点质量。常见如"Q4"≈压到 1/4 体积。
MoE（混合专家）模型很大，但每次只叫醒一小部分"专家"干活，所以大而不慢。
Token模型读写字的最小单位，约等于英文半个词、中文一个字；API 按它计费。
Harness（外壳）套在模型外面的程序，让模型能自己读文件、改代码、跑命令，从"聊天"变"干活"。
GGUF / MLX两种本地模型文件格式：GGUF 通吃（llama.cpp/Ollama），MLX 专为苹果芯片优化。

7用什么机器跑

8为什么大家往本地跑

三个推手，按社区讨论热度排序。

💸
1. 订阅变贵、说变就变

2026 年 API 涨价收紧（社区称"Great Token Reckoning"）；4 月 Claude Code 一度被移出 $20 档引发退订潮；第三方工具 OpenClaw（约 13.5 万实例）被禁用在 Claude 订阅上。r/LocalLLaMA 出现高赞帖：《Only LocalLLaMa can save us now》。

🔒
2. 代码不能外传

客户 NDA 代码、医疗/金融数据、公司合规——本地模型"永远看不到计费仪表盘、服务条款更新、速率限制和 Prompt 政策变更"。美国政府设备已限制使用 DeepSeek 等中国模型，企业侧合规需求进一步放大。

✈️
3. 离线 + 不看脸色

飞机上能干活、没有速率限制、没有"今天这个功能不让用了"。开发者原话："我再也不用想 token 价格、配额、时段，或者数据敏感不敏感。"反方观点同样在场：轻量用户买 GPU 其实回不了本。

9本地模型的边界：70% 问题

社区最诚实的一条共识：本地模型能覆盖日常编码的约七成，剩下的三成仍归云端前沿模型。

本地模型擅长（且免费）写得快、不问配额、隐私全包；Opus 给 15 倍提速，本地 Qwen 给约 5 倍——但 0 成本。适合个人项目、离线工作、不能外传的代码。
本地模型吃亏的地方多文件上下文任务独立测试仅 2.8/5（Claude 4.5/5）；工具调用稳定性、长程一致性、指令遵循这四项"不上榜单"的能力才是 agent 编码的全部。 benchmark 分数接近 ≠ 日常体感接近。

10正在发生的三件事

如果你现在入坑，这三个趋势值得知道。

2026-10Qwen3.8-27B：本地摸到 frontier3 天 300 万次 HF 下载，智能体指数反超 Claude Opus 4.8。代价是"想太多"——日常用记得把推理档位调低，否则画个简单 SVG 都能烧 2 万 token。
技术MTP：一次猜多个 token多 token 预测已并入 llama.cpp 主线，同等硬件生成速度提升 30–110%，直接缩小本地与云端的延迟体感。
格局中国模型霸榜，美国模型讲"信任"能力榜被 Qwen/DeepSeek/GLM/Kimi 占据，但地缘合规让 Gemma、gpt-oss、Nemotron 和 Meta 新发布的 Muse Spark Open（816B，需 2 台 M5 Ultra Mac Studio）拥有"可辩护"的身位。
